NathGPT FINAL Oracle - Guide de mise a jour
===============================================

CE QUE CETTE VERSION CHANGE
---------------------------
- Plus d'embeds / grandes zones de texte pour les statuts.
- Pour une demande texte ou code :
    reflexion en cours
- Pour une image :
    generation image en cours image X%
- Le message de progression disparait quand le resultat final est envoye.
- Les reponses texte sont envoyees comme messages Discord normaux.
- Les images sont envoyees comme fichiers/images Discord normaux, sans boutons.
- Plus de bouton Modifier, Rendre PNG, Telecharger ou Historique.
- Pour modifier une image :
    reponds directement au message NathGPT qui contient l'image
    puis ecris :
    modify: ton prompt
- Pour regenerer l'image en PNG sans fond format A4 :
    reponds directement au message NathGPT qui contient l'image
    puis ecris :
    png:
- La detection des images ne depend plus du bouton "Modifier" de ChatGPT.
  Cela corrige le cas ou l'image est deja terminee mais le bot restait bloque
  vers 95 % parce que ce bouton n'etait pas repere.
- Detection ajoutee pour les images <img> et les rendus <canvas>.
- Aucun token Discord n'est inclus dans ce ZIP.

MISE A JOUR AUTOMATIQUE
-----------------------
1. Extrais le ZIP sur ton Bureau.
2. Ouvre le dossier NathGPT_FINAL_Oracle.
3. Double-clique sur :
      METTRE_A_JOUR_NATHGPT.bat
4. Attends la fin.
5. La fenetre doit afficher le statut de nathgpt.service.
6. Si tu vois :
      Active: active (running)
   la mise a jour est terminee.
